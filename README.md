# Millis — 沉浸式時鐘 / 秒錶 / 倒數 / 番茄鐘 / 目標 (PWA)

全螢幕、無干擾、顯示到毫秒的網頁時鐘，內建秒錶、倒數計時、番茄鐘與目標倒數。
可以安裝到手機／桌面當成獨立 App，離線也能用。
純靜態：沒有框架、沒有打包工具、沒有外部字型，整包丟到任何靜態空間就會動。

## 快速試玩

```bash
cd clock
python3 -m http.server 8080
# 打開 http://localhost:8080
```

> 安裝與離線功能需要 **HTTPS** 或 **localhost**。用 `file://` 直接開只會看到時鐘、裝不了 App。

## 架到 GitHub Pages

這個專案已經附好 `.github/workflows/pages.yml`，不需要建置步驟。

1. 把這個分支合併進 `main`
2. GitHub repo → **Settings → Pages → Source** 選 **GitHub Actions**
3. 推上去之後 Actions 會自動發佈，網址是 `https://<你的帳號>.github.io/clock/`

Pages 有免費 HTTPS，所以 PWA 的安裝與離線都能正常運作。
網站會放在 `/clock/` 這個子路徑底下，專案裡所有路徑（manifest 的 `start_url`、`scope`、Service Worker 快取清單）都是相對路徑，所以子路徑不會出問題。

## 五種模式

用底部控制列切換，或按 <kbd>1</kbd> <kbd>2</kbd> <kbd>3</kbd> <kbd>4</kbd> <kbd>5</kbd>。

### 時鐘
毫秒級即時時間、日期、時區名稱。

### 秒錶
開始／暫停／繼續、計圈、重設。計圈列表會標出**最快（綠）**與**最慢（紅）**，同時顯示單圈與累計時間。

### 倒數
1／3／5／10／15／25／45／60 分快速選，或自訂時／分／秒。跑的時候可以按「+1 分」加時間。
時間到會**閃畫面 + 提示音 + 震動**（後兩者可在設定關閉）。

### 番茄鐘
專注 → 短休息 → 專注 → …，做滿設定的輪數之後換長休息，然後重新開始。
畫面上會顯示目前階段（專注／短休息／長休息）、剩餘時間，以及這個循環的進度點點。
可以「跳過」本段直接進下一段，也可以「重設」整個循環。
預設是 25 / 5 / 15 分、4 輪長休息，每段結束都會自動接續下一段（可在設定關掉，改成手動按開始）。

### 目標
設定一個**確切的日期時間**（例如 2027/01/01 00:00），一路倒數到那一刻。

- **越接近，數字越紅**。紅的程度是對數變化的：還有一個月時幾乎是原色，剩一天開始明顯偏紅，剩一小時很紅，最後一分鐘全紅。用線性的話前面幾天會完全看不出差別。
- **跨過那一瞬間轉成綠色，並加上 `+` 開始正計時**，同時閃畫面提示一次。
- **可以同時設定很多個目標**。清單會自動排序：還沒到的近的在前，已經過的排後面。點清單任一列就把大字換成那個目標，✕ 刪除。
- 超過一天會顯示成 `127天 23:59:59`。

> 秒錶、倒數與番茄鐘用的是**單調時鐘**（`performance.now()`），系統時間被調整也不會跳掉。
> 進度會存起來，關掉分頁或重整都接得上；如果人不在的時候時間到了，回來會補一次提示。
> 番茄鐘專注時如果覺得毫秒跳動很吵，按 <kbd>M</kbd> 可以關掉毫秒。

## 設定（點 ⚙）

**時間**：24／12 小時制、時區（跟隨裝置或完整 IANA 清單，夏令時間自動處理）、秒／毫秒／日期／時區名稱開關

**秒錶與倒數**：結束提示音、結束震動、計圈列表開關

**番茄鐘**：專注時間、短休息、長休息、幾輪後長休息、是否自動接續下一段

> 目標時間是在「目標」模式的畫面上直接新增與刪除，不在設定頁裡。

**外觀**：深淺模式（跟隨系統／淺色／深色）、5 種色調、4 種系統字型、字重、字體大小 40–160%

**效果**：發光強度、冒號閃爍、切換淡入、控制列自動隱藏秒數、螢幕不休眠

設定存在瀏覽器本機，下次打開就在。按「恢復預設值」可重來。

## 幾個關鍵的技術決定

**1. 用 `requestAnimationFrame`，不用 `setInterval(…, 1)`**
`setInterval` 最快大約只有 4ms，而且會跟螢幕更新錯開、看起來會頓。rAF 跟著螢幕的節奏跑（60Hz 約 16ms、120Hz 約 8ms），畫面最順也最省電。

**2. 時鐘每幀重問系統時間；秒錶／倒數／番茄鐘改用單調時鐘**
時鐘要的是「現在幾點」，所以每幀重讀 `Date.now()`，分頁切走再回來也不會跑掉。
秒錶／倒數／番茄鐘要的是「過了多久」，用 `performance.now()`：它只會往前走，不受使用者調時間或夏令時間影響。跨重整的接續則另外用 `Date.now()` 記錄離開的時間點來補。

**3. 只有數字真的變了才動 DOM**
時分秒一秒才變一次，沒必要每幀重寫。搭配 CSS `tabular-nums`（等寬數字），毫秒狂跳時整排數字也不會左右抖。
> 這裡有個容易踩的坑：判斷「有沒有變」的初始值要用 `null` 而不是空字串，否則「AM 變成空白」這種變化會被誤判成沒變，舊文字就擦不掉。

**4. 時區換算只算一次，不是每幀算**
`Intl.DateTimeFormat` 很貴，每秒跑 60 次會很浪費。做法是每 10 秒算一次「目標時區跟 UTC 差幾毫秒」，之後每幀只做一次加法。10 秒也足夠即時反映夏令時間切換。

**5. 目標的顏色用對數插值**
剩餘時間的尺度跨很多個數量級（幾個月 ↔ 幾秒），線性對應會讓大部分時間都停在同一個顏色。做法是在 7天 / 1天 / 1小時 / 1分鐘 這幾個錨點之間用 `log10` 插值，所以每個尺度都感覺得到變化。顏色本身用 CSS `color-mix` 把主色和警示紅混合，深淺模式各有一組紅與綠，兩種背景下都看得清楚。

**6. 兩層保險讓字永遠塞得下**
先依「目前實際顯示幾個字元」挑一個基準字級檔位（`12:34:56.789` 用小一點、`25:00` 用大一點），再量實際寬高算出 `--fit` 係數收尾。字型、字重、字級、格式怎麼組合都不會被切掉。

## 已知限制

- iOS Safari 沒有全螢幕 API。做法是**加到主畫面**後開啟，`display: fullscreen` 就會自然全螢幕。
- Wake Lock 目前 iOS Safari 支援有限；不支援時設定頁會直接標示出來。
- 倒數的提示音需要瀏覽器允許播放聲音，所以第一次一定要先有點擊動作（按「開始」就算），這是瀏覽器的規則。
- 顯示精度受限於瀏覽器：基於資安考量（防側通道攻擊），時間 API 在部分瀏覽器會被刻意降低精度，誤差在數毫秒等級。當一般時鐘與秒錶綽綽有餘，但**不適合當正式比賽的計時器**。
